# M25 - Glassmorphism Login & Registration Portal

A modern, responsive authentication interface built with HTML5, CSS3, and Vanilla JavaScript, featuring advanced glassmorphic aesthetics.

## ✨ Features
- **Internet Vector Backgrounds**: Dynamic scalable vector (SVG) graphics from the internet (with local asset fallbacks) featuring customizable presets: Geometric Hexagons, Cosmic Nebula, Cyber Code Matrix, Abstract Waves, and Celestial Dust with interactive dropdown switcher and session persistence.
- **Glassmorphic UI**: Frosted glass blur (`backdrop-filter`), multi-layered reflections, and subtle borders.
- **Ambient Animated Blobs**: Fluid background gradient orbs for refraction and depth.
- **Dual Mode Switcher**: Quick toggle between **Sign In** and **Sign Up** forms.
- **Password Visibility**: Show/hide toggle button with dynamic SVG icons.
- **Form Validation & Feedback**: Client-side validation with error indicators and animated loading state on submit.
- **Mobile Responsive**: Optimized across all modern screen sizes and devices.

## 🚀 Getting Started
Simply clone the repository and open `index.html` in any modern web browser or serve it through your local web server (e.g., MAMP, Live Server, Nginx, or Apache).
